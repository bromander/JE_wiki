Спрайты это неотъемлемая часть каждой визуальной новеллы.

## Добавление спрайтов персонажей

Чтобы добавить спрайт персонажа, достаточно использовать функцию `show_character` у класса `Scene`:

``` python
show_character(character: str,  
                at = None,  
                effect = None,  
                stream: Literal["consistently", "together"] = "consistently"
                ) -> None:
```

#### character
Обозначает имя спрайта
#### at
Обозначает положение спрайта. 
Подробнее: [[Дополнительно#at]]
#### effect
Эффект, который будет применён к спрайту при появлении на экране.
Подробнее: [[Дополнительно#Эффекты]]
#### stream
Обозначает то, в каком потоке спрайт появится. 
Подробнее: [[Дополнительно#Потоки]]


## Удаление спрайтов персонажей со сцены

Чтобы убрать персонажа со цены, нужно вызвать функцию `hide_character`, класса `Scene`:

``` python
hide_character(character: str,  
                effect = None,  
                stream: Literal["consistently", "together"] = "consistently"
                ) -> None:
```

#### character
Обозначает имя спрайта
#### effect
Эффект, который будет применён к спрайту при исчезновении с экрана.
Подробнее: [[Дополнительно#Эффекты]]
#### stream
Обозначает то, в каком потоке спрайт появится. 
Подробнее: [[Дополнительно#Потоки]]
