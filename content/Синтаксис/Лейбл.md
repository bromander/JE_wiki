
Каждый сценарий состоит из лейблов.
**Лейбл** - блок сценария, которым обычно разграничивают сценарий для улучшения структурированности кода.


# Лейбл

Чтобы обозначить **начало лейбла** в сценарии, нужно вписать команду:

``` python
label <Название лейбла>(name, description, duration, show_splash):
```

Сценарий всегда начинает идти от самого первого лейбла - **main**.
Т.е. ваш сценарий всегда должен начинается с `label main():`.

После двоеточия можно начать писать весь последующий сценарий.
## Аргументы

Все эти аргументы в целом необязательны
#### name
`str`
Обозначает название лейбла, которое будет отображаться в активностях дискорда и названии сохранения.
#### description
`str`
Описание лейбла, которое будет отображаться в активностях дискорда и названии сохранения.
#### show_splash
`bool`
Включает плашку (сплеш) сверху экрана с названием и описанием лейбла, при переходе на этот него.
#### duration
`float`
Скорость появления сплеша. Скорость пропадания всегда в 2 раза меньше
