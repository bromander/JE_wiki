

# Потоки
Все визуальные эффекты работают за счёт функций-генераторов, которые могут выполнятся в 2 разных потоках:

1. `Together` - функции выполняются **одновременно**
2. `Consistently` - функции выполняются **друг за другом** (т.е вначале первый, потом второй и так далее)


# Эффекты
Все эффекты для спрайтов лежат в классе SpriteEffects

Пример использования:
``` python
Scene.show_character("edwin smile", at="right", effect=SpriteEffects.Dissolve(1.0))
```

### Dissolve
``` python
SpriteEffects.Dissolve(duration: float)
```

С этим эффектом спрайт появляется/пропадает растворяясь


#  Аргументы

## at
Аргумент `at` обычно требует **положение спрайта**.
Он может представлять из себя несколько типов данных: `str`, `tuple[int]` и `tuple[float]`


**`str`**:
Чтобы быстро и максимально просто установить положение спрайта, можно просто ввести в аргумент то, какое положение вам нужно: `"left"`, `"right"` или `"center"`.

**`tuple[int]`**:
Для точного расположения спрайта на экране, можно ввести в значение аргумента можно вставить кортеж со значениями X и Y

**`tuple[float]`**:
Вместо того, чтобы вводить точные значения координат, можно ввести положение относительно экрана. К примеру, значения `(0.1, 0.5)`  поставят объект по координатам `(192, 540)` (т.е. $0.1 * 1920$, $0.5 * 1080$, при размере монитора 1920 x 1080)
